# Vectors

### What does a vector in geometrically ?
It is a direction with coordinates

### When you add two NumPy arrays element-wise, what does that look like as a physical movement in 2D space?
A perpendicular vector will be created and new direction will be discovered

### What would two similar products look like relative to each other?
2 overlapping vectors 

### if I give you two vectors [1,0] and [0,1], can you reach every point in 2D space by scaling and combining them? What if both vectors pointed in the same direction?
Yes we can reach every point in 2D
by multiplying values to [1,0] & [0,1] can conver all points in x axis and y-axis
by combining and multiplications of different combination can cover all the points in the space between x-axis and y-axis
if both vectors in same direction then only covers positive x and y values but how [1,0] & [0,1] will be in same direction.

### What will happen if 2 feature columns are correlated ?
If correlated then either 2 vectors will be in same direction or the angle between the vectors will be less/minimal

### linearly dependent :
It means if one vector increase/decreased then the other vector also increases/decreases by some factor respectively.
